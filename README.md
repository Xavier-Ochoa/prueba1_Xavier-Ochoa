Aplicación móvil desarrollada con Ionic + Angular para la materia **Desarrollo de Aplicaciones Web**.  
La aplicación permite autenticación de usuarios, consulta de libros mediante API externa y gestión de fotografías almacenadas localmente en el dispositivo.

# 🚀 Tecnologías utilizadas

- Ionic Framework
- Angular
- TypeScript
- Capacitor
- Supabase Authentication
- Open Library API
- Camera API
- Filesystem API
- Preferences Storage

---

# 📱 Funcionalidades principales

## 🔐 Autenticación de usuarios

- Registro de usuarios
- Inicio de sesión
- Cierre de sesión
- Protección de rutas mediante Guards

---

## 📚 Consumo de API

La aplicación consume la API pública de Open Library para:

- Buscar libros
- Mostrar listados
- Ver detalles de cada libro
- Manejar errores y estados de carga

---

## 📸 Gestión de fotografías

La aplicación permite:

- Tomar fotografías con la cámara del dispositivo
- Mostrar imágenes capturadas
- Guardar fotos localmente
- Recuperar fotos almacenadas
- Eliminar fotografías

---

## 🧭 Navegación

- Navegación mediante Tabs
- Rutas protegidas
- Organización modular de páginas y servicios

# ⚙️ Instalación del proyecto

## 1. Clonar el repositorio

```bash
git clone https://github.com/USUARIO/REPOSITORIO.git
```

---

## 2. Instalar dependencias

```bash
npm install
```

---

## 3. Ejecutar el proyecto

```bash
ionic serve
```

---

# 📲 Compilación Android

## Generar build

```bash
ionic build
```

## Sincronizar Capacitor

```bash
npx cap sync android
```

## Abrir Android Studio

```bash
npx cap open android
```
